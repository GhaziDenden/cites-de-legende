Privacy Policy

Last updated: November 13, 2026

Bobine is a private, single-user tool. Its only user and only data subject is the creator of the Cités de Légende channel, connecting their own accounts to publish their own content. Bobine has no end users, no sign-up, and no accounts other than the operator's own.

What Bobine accesses on TikTok

Bobine uses TikTok Login Kit and the Content Posting API only so that the channel's operator can connect and publish to their own TikTok account:

  • user.info.basic: to confirm which TikTok account is connected.
  • video.upload and video.publish: to upload finished video files from the operator's own computer directly to that same account (Direct Post, by file upload, never by referencing an externally hosted URL).

No other TikTok account, and no TikTok user other than the operator, is ever accessed.

What is stored, and where

Bobine runs entirely on the operator's own computer. The access token TikTok issues is stored on that computer so the operator does not have to sign in on every use, and it is only ever sent to TikTok's own API. Bobine has no server, no database, and no storage outside the operator's own computer.

What is never done

Bobine does not sell, share or disclose any data to third parties. It does not use TikTok data for advertising, profiling, or anything beyond publishing the operator's own content and confirming it was published. It collects no data about TikTok viewers, commenters, or any account other than the operator's own.

Other platforms

The same rule applies to Bobine's YouTube and Meta (Facebook and Instagram) integrations: each is used only to publish the operator's own content to the operator's own accounts.

This website

This website sets no cookies and runs no analytics. Video thumbnails are loaded from YouTube and fonts from Google Fonts, which receive the standard information any browser sends when loading an image or a font.
